# Interaction Design

Establish user tasks, existing design language, content and device constraints.
Model loading, empty, success, failure and interruption states. Use semantic
structure, keyboard/focus behavior, contrast and reduced motion. Provide
inspectable alternatives and clear component/state specifications. Distinguish
design intent from implemented or browser-verified behavior.
