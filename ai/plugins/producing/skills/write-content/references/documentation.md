# Documentation

Define reader, task, source of truth and format. Verify instructions and
examples against supplied interfaces, distinguish versions and prerequisites,
and keep navigation, terminology and error explanations coherent. API
documentation must preserve actual request/response/error contracts. Track
untested examples and unsupported claims; publication and documentation-site
builds require their own scope.
