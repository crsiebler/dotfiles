# GIF validation

Structural verification reopens the generated bytes with Pillow and iterates the
actual decoded frames. It reports per-frame durations, summed elapsed milliseconds,
loop extension (null when absent), dimensions, format, disposal, byte size, and
frame count. Input requested timing and encoded timing are separate fields.

Inspect representative frames over the intended background. For transparency,
verify areas occupied by the previous frame clear on the next (disposal 2), and
check edges after alpha thresholding. Check stable alignment, aspect ratio, palette
loss, readability, motion cadence, final-to-first continuity, and playback in the
actual destination when available. Encoding success is not visual approval.

Regression coverage should include repeated images, reduction groups, nonuniform
and non-10-ms timing, one-frame output, absent/finite/infinite looping, letterboxing,
nearest pixel edges, transparent clearing, malformed images/requests, output size
limits/collisions, escaped or symlinked paths, missing Pillow, and source hashes.
Run copied helpers from an unrelated project working directory and verify installed
resources remain unchanged. Do not hide unavailable dependency or visual checks.
