# Slack destination guidance (conditional)

Load this reference only for Slack delivery. A 128x128 canvas and a small palette
can be useful starting presets for emoji; larger message artwork needs a different
readability tradeoff. These are suggestions, not verified Slack upload limits.

Before claiming compatibility, inspect current official Slack documentation and
any workspace-specific policy for the actual destination (custom emoji versus
message attachment). Record the checked source/date and compare actual bytes,
dimensions, format, and animation behavior. No current Slack limit is certified
by this package. Do not automatically upload or post the artifact.
