# Delivery Planning

Map dependencies, capacity, risks, milestones and acceptance. Distinguish
estimates from commitments, document decisions and ownership, and use
ceremonies only when they serve a real coordination need. Planning does not
start execution or update external trackers. Use existing progress/status
skills for evidence-backed reporting.
