# Report Project Status

Read [reporting contract](references/reporting.md) and
[source adapters](references/sources.md). Resolve project, audience, dates and
timezone, source scope, expected workflow, and reliable identity mappings.
Collect read-only evidence; distinguish period activity from current state,
commits from deployments, and reported concerns from verified facts.

Adapt sections to the audience. State material gaps without interpreting missing
activity as no work. Do not infer team well-being from activity counts. Default
to a conversational report; save only to a requested project-local path. This
workflow does not post externally or change source state.
