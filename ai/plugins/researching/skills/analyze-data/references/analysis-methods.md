# Analysis Methods

Establish question, units, grain, population, missingness and provenance.
Validate joins, sampling, leakage and assumptions before analysis. Separate
exploratory findings from confirmed hypotheses; report uncertainty,
confounders, limitations and reproducibility. Backtests need explicit costs,
chronology and out-of-sample checks; do not infer future performance or trading
authority. Protect input data and keep computational outputs in authorized
scratch/artifact paths.
