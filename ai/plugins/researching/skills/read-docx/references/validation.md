# Validation and evidence

Validate package size, expanded size, ZIP integrity, and required document member
before extraction. Cite source-relative path, SHA-256, and record locations.
Check unsupported counts and truncation before drawing conclusions. Heading levels
come from recognizable Heading 1–9 or Title paragraph styles and their inheritance;
custom outline levels and localized style names may not be recognized.

Regression fixtures independently create interleaved paragraphs/tables, a nested
table, revision-wrapped text, Unicode headings, and inherited/default/disabled
first-page headers and footers. They check supported order, cell coordinates,
omission reporting, omitted leading grid positions and merged cells, bounded excerpts, unchanged source hashes, missing packages,
invalid packages/limits, and path/symlink restrictions. An isolated reader copy
runs without any creation skill and leaves all source/installed bytes unchanged.

Header/footer context represents stored definitions and enabling settings, not
rendered pages. Drawings, fields, notes, comments, tracked changes, and other
unsupported structures require additional inspection when relevant. No renderer
was invoked; extraction does not verify pagination, glyphs, or visual completeness.
