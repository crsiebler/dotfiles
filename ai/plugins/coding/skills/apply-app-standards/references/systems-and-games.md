# Systems And Games

Establish hardware, engine, transport, platform and resource constraints. Own
lifetimes, scheduling, synchronization, device faults and graceful degradation.
For games, preserve simulation timing, input, networking and asset lifecycles.
For audio, separate gameplay state from playback, manage voices, streaming,
clipping, transitions and teardown; choose native audio or middleware from
project requirements. Measure resource budgets on target hardware. Generation
uses the separately advertised create-audio/create-sprites workflow and its
authorization; never assume a provider or fixed codec/duration range.
