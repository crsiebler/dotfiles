# Requirements

Reading supplied evidence and authoring plans requires no additional package.
Use the target project's existing tools, declared versions and documented setup
for authorized execution; inspect availability without installing or starting
services. No provider, model runtime or delegation capability is assumed.

If a tool or target is unavailable, report the exact limitation. For separately
authorized setup follow project instructions and official documentation for the
declared version; no universal install command applies. Provider authentication,
external access, model calls, service operations and global changes require their
own applicable authority. AI installation does not provision these dependencies.
