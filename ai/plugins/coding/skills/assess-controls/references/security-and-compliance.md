# Security And Compliance

Inspect only authorized artifacts and supplied evidence. Trace trust
boundaries, exposed capabilities, data handling and control coverage.
Distinguish policy/configuration from observed operation and absent evidence
from a confirmed control failure. Map applicable standards only with known
scope, jurisdiction and current sources. Return prioritized, located findings
and proposed validation; do not run tests, remediate or claim certification.
