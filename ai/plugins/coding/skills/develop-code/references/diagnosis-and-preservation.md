# Diagnosis And Preservation

Separate diagnosis from authorized repair. Establish expected versus actual
behavior and an attributable baseline. Form falsifiable hypotheses, trace the
causal path, and use the smallest relevant reproduction when execution is
allowed. Preserve public behavior during refactoring with characterization
evidence. Modernize incrementally at tested boundaries; avoid speculative
abstraction and unrelated rewrites.
