# Builds And Dependencies

Inspect manifests, lockfiles, build graph, caches and reproducibility before
changes. Measure an affected build path before optimizing it. Preserve
dependency provenance, compatibility, license constraints and supply-chain
controls. Installation, upgrades and CI changes require their applicable
authority; existing build failure is not permission to bypass checks.
