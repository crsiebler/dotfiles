# Performance Analysis

Specify workload, dataset and measurement conditions. Inspect profiles/query
plans and establish a baseline before tuning. Preserve result semantics,
concurrency and transaction behavior. Compare relevant measurements after the
scoped change; do not invent latency or coverage targets, mandate caching or
infer production gains from unrelated fixtures.
