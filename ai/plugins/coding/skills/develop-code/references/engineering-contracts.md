# Engineering Contracts

Establish observable behavior, public interfaces, errors, lifecycle and
ownership before editing. Trace UI-to-service-to-storage boundaries where
relevant; preserve cancellation, retries and compatibility. Use the actual
target platform, semantic UI, accessible interactions and existing components.
Verify changed success and failure paths; report missing browser/device checks.
