# Requirements

Source/read/search tools and non-mutating Git inspection are required for local
staged candidate evidence. Native delegated use needs callable reviewer
and actual same-session continuation; inspecting a definition proves neither.
The workflow must supply the full contract and packet. Plain session invocation
is supported; no goal API, daemon, runner or additional package is required.

Execute mode additionally needs the project's already available check tools,
a candidate-equivalent execution root, approved private outputs and resource
ownership, and command/count/time limits. Use project instructions to find checks;
do not install dependencies, provision services or widen runtime permissions.
Report missing required capabilities as blocked and optional ones as gaps.

Check Git availability with git --version. If missing, separately authorized
user setup is documented at https://git-scm.com/downloads. Project dependencies
and any browser capability follow the project's own documented setup. No automatic
installation or authentication is part of review.
