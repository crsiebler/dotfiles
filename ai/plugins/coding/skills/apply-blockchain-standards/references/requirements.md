This instruction-only bundle requires no package to read supplied artifacts.
Implementation/verification uses the project's declared toolchain and existing
tests. Inspect manifests, lockfiles, documented commands and runtime versions.
Native delegation, network tools and a particular provider are not prerequisites.

Use project-documented version/check commands only when runtime and task scope
permit execution; inspection-only work uses supplied evidence. Report missing
tools/targets without substituting unrelated runtime results. No dependency setup,
service provisioning, authentication or external operations are implicit.

For separately authorized setup, use the project's installation recipe and
official vendor documentation for its declared version. No universal installation
command or dependency version applies across technologies. AI installation does
not provision these runtimes.
