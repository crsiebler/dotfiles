### Test adequacy questions

- Which changed contract and plausible defect does each assertion exercise?
- Are success, failure, boundary and integration cases realistic?
- Does isolation cover shared state, cleanup and partial setup?
- Which results are observed, unavailable or outside the test boundary?
- Are flakiness and improvement claims supported by measurements?
