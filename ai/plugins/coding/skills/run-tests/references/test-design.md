# Test Design

Select tests for behavioral risks, acceptance criteria and failure modes.
Prefer existing runners and sensitive regressions over framework replacement.
Use realistic doubles, isolated fixtures and explicit resource ownership.
Distinguish test authoring (implementation owner) from independent execution (reviewer);
inspection-only tasks do not execute. Do not change assertions to conceal
failures.
