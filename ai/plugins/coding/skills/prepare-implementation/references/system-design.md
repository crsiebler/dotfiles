# System Design

Start from consumers, workload, existing constraints and failure boundaries.
Compare alternatives using compatibility, coupling, operational cost and
recovery implications. Specify API errors, consistency and evolution. Keep
monoliths, services and cloud vendors as choices justified by requirements.
Design does not authorize provisioning or changing access controls.
