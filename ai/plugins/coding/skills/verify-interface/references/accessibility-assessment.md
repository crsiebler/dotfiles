# Accessibility Assessment

Inspect keyboard navigation, focus lifecycle, semantic names/roles/states,
contrast, zoom, reduced motion and error feedback. Select actual target
platforms and assistive technologies. Automated checks cover only part of
accessibility; report which manual/browser checks were performed and do not
claim blanket compliance.
