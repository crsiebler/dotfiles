# Prompt Evaluation

Define trusted instructions, retrieved data boundaries, variables, output
parsing and failure behavior. Keep conditional knowledge in loadable
references. Evaluate normal, adversarial, missing-tool and non-trigger cases
against an immutable baseline; reserve holdouts and disclose visible tuning
cases. Record actual model/settings, repetitions and outcomes when model calls
are authorized. Static checks and generated test requests are not model-
behavior evidence.
