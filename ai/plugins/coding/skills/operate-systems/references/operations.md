# Operations

Confirm target environment, authority, current state and resource ownership.
Use an exact change plan with impact, stop conditions, backups/recovery
prerequisites and success checks. Treat build artifacts, database recovery,
network reachability and service health as separate evidence. Never equate a
command exit code with recovered user behavior or promise zero downtime without
evidence.
