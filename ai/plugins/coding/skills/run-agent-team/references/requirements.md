# Requirements

Instruction-only planning/inspection needs no package. Team execution requires
Codex native spawn/follow-up/wait/session inspection facilities, supported explicit
worker model selection, permitted delegation and known capacity. Both modes need
exact dedicated reviewer selection and same-session continuation when required by
the existing risk budget. Delegated mode additionally requires callable coordinator
role/model selection and nested delegation. Parent-direct mode requires a selected
Sol parent and readable discovered coordinator instructions, without a coordinator
child or nesting. Inspect the
actual schema; never invent `agent_type`, a cwd argument, nested support or model
telemetry. A role file is not evidence of native invocation. Direct-lead fallback
does not relax required reviewer capabilities.

Require Git, approved clean committed integration/task branches and worktrees,
the advertised prepare-implementation shared contracts, and project-native
verification tools. Worktree lifecycle, commits, model use and sensitive operations
need applicable scope; reuse existing authorization. No new package, scheduler,
service, plugin, authentication or global installation is a runtime prerequisite
that this skill may provision for itself.

Inspect installed role settings and runtime defaults before model calls. A custom
role's model fields may override explicit spawn/default selection; a conflicting
pin is a blocker until separately authorized activation/reconciliation. Source
omission is not installed inheritance. Record requested settings and available
selection evidence; do not invent the service's effective model or usage.

Python 3.11+/POSIX requirements for the existing archive helper remain in its
own advertised bundle. Authoring validation uses create-skill's existing Python
and PyYAML environment; these are not new team runtime dependencies.

Availability checks are read-only native schema/registration/configuration and Git
inspection. Live native/model smoke tests need their own bounded execution grant.
No install command or automatic capability-probe agent is supplied.
