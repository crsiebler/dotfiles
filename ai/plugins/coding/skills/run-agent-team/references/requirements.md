# Requirements

Instruction-only inspection needs no package. Codex team execution requires
native spawn/follow-up/wait/session inspection, explicit supported worker model
selection and known capacity. The selected Sol main thread owns direct dispatch,
Git integration and canonical trackers. Exact dedicated reviewer selection and
same-session continuation are required where the existing risk budget specifies
native review. Inspect actual schemas; never invent arguments or effective model
telemetry. No coordinator child or nesting capability is required.

Require Git, approved clean committed integration/task branches and worktrees,
this bundle's shared execution contracts and project-native verification tools.
Lifecycle, commits, model use and sensitive actions require actual scope.
Inspect installed role pins; source omission is not installed inheritance.
No automatic provisioning, installation, authentication or live capability probes.

The archive helper requires existing Python 3.11+ and POSIX tools. Use a validated
existing interpreter, including Conda's active `python`; no environment creation.
Authoring validation uses create-skill's existing Python/PyYAML environment.
Ralph resource-only consumers use their own runner requirements and do not enter
Codex team preflight or require team model/worker controls.
