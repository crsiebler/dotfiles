# Requirements

The helper uses Python 3.11+ standard library, Git and POSIX file-lock/process
facilities. Validate an existing interpreter, including active Conda python or a
newer interpreter exposed only as python3. No package/model/network dependency.

Read-only --dry-run validates without writes. Normal archival/preservation needs
actual exact-path authority; active-copy removal and closeout commits retain their
separate scope. Discovery/installation is not approval. Resolve the helper only
from this advertised installed archive-run bundle; no guessed sibling/cache paths.
Do not install environments, tools, credentials or global settings automatically.
