# Workflow Systems

For software workflow systems, model state transitions, idempotency, retries,
backpressure, deadlines, cancellation, compensation and human checkpoints from
actual failure modes. Use the simplest sufficient implementation; a finite-
state machine is optional. Specify resource/fairness constraints and observed
service targets rather than universal recovery times. This software-design
knowledge grants no agent-dispatch or operational authority.
