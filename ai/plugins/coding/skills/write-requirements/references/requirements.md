# Requirements

## Required and conditional dependencies

Drafting a PRD from supplied context needs no external utility, language runtime,
or provider login. Native file/search tools are sufficient for local evidence.
Live research or source-document extraction uses the selected advertised skill
and its own requirements. Project execution dependencies are not prerequisites
for defining outcomes and acceptance criteria.

## Setup and checks

No installation is needed for the baseline workflow. Discover tools through the
active runtime before requesting a connector or package. If web/provider access
is unavailable, use supplied evidence and identify unresolved facts.
If a reader or browser helper is selected, load that skill's requirements and
follow its separately authorized setup; do not install dependencies merely
because a future implementation might use them.

Requirements drafting does not authorize application startup, dependency
installation, model calls, archival/removal, or implementation.
